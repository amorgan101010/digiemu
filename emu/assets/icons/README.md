# Window icons

One original drawing per product, in the sizes a taskbar asks for. No
photographs, vendor wordmarks or product logos. `emu/dtpanel.py` loads the
set named after its product; without the files the window keeps Tk's icon.

Drawn by `icons/make_icons.py` in the elektremu studio tree and copied here by
its `icons/install.sh`. The 16 and 24 px files are a plainer drawing, not the
larger one scaled down.
